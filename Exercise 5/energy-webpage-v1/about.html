About Us

Welcome to the Appliance Energy Consumption Website. This website was created as part of COS30045 Data Visualisation.

About This Website

The purpose of this website is to provide a simple demonstration of HTML, CSS and JavaScript while introducing the concept of appliance energy consumption.

The website focuses on presenting information in a simple and accessible format. It also provides a foundation for future data visualisation exercises.

What We Aim to Demonstrate

This project demonstrates how multiple web pages can be connected using HTML navigation, styled consistently using external CSS and enhanced with JavaScript interactivity.

The project also demonstrates the use of GitHub for version control and maintaining a history of development changes.
